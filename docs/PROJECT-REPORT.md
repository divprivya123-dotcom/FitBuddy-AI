# FitBuddy Project Report

FitBuddy is a FastAPI application that uses Google Gemini to generate personalized seven-day fitness plans and nutrition or recovery guidance.

## Project Outcome

The application accepts a user's fitness profile, generates and stores a plan, and supports feedback-based revisions while retaining the original plan.
