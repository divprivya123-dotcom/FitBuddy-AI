# Phase 08 - Project Demonstration

## Demonstration Flow

1. Start the FastAPI server and open the FitBuddy home page.
2. Enter a user profile with a fitness goal and intensity.
3. Generate and review the seven-day plan.
4. Submit feedback and show the revised plan.
5. Open `/view-all-users` to demonstrate stored user and plan records.
6. Explain the Gemini integration, database persistence, validation, and failure handling.

## Demonstration Notes

The full workflow requires the application server, a valid Gemini API key, and the configured database. The GitHub Pages preview is static and cannot perform plan generation or persistence.
