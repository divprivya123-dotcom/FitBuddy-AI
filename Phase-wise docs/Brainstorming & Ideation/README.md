# Phase 01 - Brainstorming & Ideation

## Objective

Identify a practical fitness problem that can be improved with Generative AI.

## Problem Identified

Many users need a simple, personalized workout plan but do not know how to combine their goals, available intensity, and basic health information into a consistent weekly routine.

## Proposed Idea

Build FitBuddy, an application that accepts a user profile and generates a practical seven-day workout plan with nutrition or recovery guidance.

## Expected Outcome

A usable fitness assistant that gives structured guidance and can improve a plan from user feedback.
